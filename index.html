Project 02 — 06
AI security · Research

VMI — Visual Memory Injection

Mar 2026 – May 2026
Co-authored with Aadit Gulati
Accepted at IEEE ICIIS 2026
GitHub↗

Adversarial attacks on multi-turn vision-language models — and the behaviour-level defense that catches them.

  • Implemented a PGD-based adversarial attack on CLIP ViT-L/14 that applies imperceptible pixel perturbations (≤ 8/255) to shift image embeddings toward an attacker-chosen semantic target — achieving 80% success rate and a mean cosine shift of 0.31 across 20 test images.
  • Evaluated four detection strategies — Feature Squeezing, Embedding Anomaly Detection, Nearest Neighbour Analysis and Conversation Drift Detection — and identified why embedding-space detectors fundamentally fail: PGD deliberately steers adversarial embeddings into the benign distribution, making them invisible to anomaly-based methods.
  • Introduced Conversation Drift Detection, a novel behaviour-level defense that monitors semantic trajectory across conversation turns using SentenceTransformer — achieving AUC 1.000 and 100% classification accuracy on the test set.
  • Feature Squeezing achieved AUC 0.925 as the strongest image-level detector; together the two defenses form a recommended two-layer post-hoc monitoring strategy requiring zero model retraining.
Python CLIP ViT-L/14 PGD Attack AI Security SentenceTransformer Isolation Forest Adversarial ML Google Colab T4

CORTEX

Jan 2026 – Apr 2026 · Team of 4
Guided by Dr. Bhavana Kaushik
Accepted at FiCloud 2026 (CSW Workshop)
GitHub↗

A context-aware authentication threat intelligence system that scores every login attempt — and explains itself.

  • Built a 13-module authentication analysis pipeline in Flask that evaluates every login attempt through velocity detection, impossible travel checking, device fingerprinting, threat intelligence feed cross-referencing and behavioural baseline comparison.
  • Designed a contextual risk scoring engine (LOW / MEDIUM / HIGH) with risk memory escalation — prior HIGH-risk history amplifies future scores — and a risk decay mechanism that gradually reduces scores for sustained clean behaviour.
  • Implemented an explainability module that generates human-readable justifications for every flagged login, making the system fully auditable for Security Operations Centre use.
  • Built a React-based security monitoring dashboard with real-time alert views, threat logs, enforcement history and user activity overview.
